# Santana Medley CD Shop 🎵

Интерактивный учебный интернет-магазин музыкальных дисков, созданный с использованием HTML, CSS и JavaScript/jQuery.

Проект был разработан в рамках учебной работы и представляет собой полноценный клиентский интерфейс интернет-магазина с каталогом товаров, интерактивной корзиной и адаптивной вёрсткой.

## ✨ Features

### Каталог товаров

- Карточки музыкальных дисков
- Название товара
- Цена
- Изображение
- Информация о доступном количестве
- Возможность добавить товар в корзину

### Интерактивная корзина

Реализована полноценная клиентская логика корзины:

- добавление товара;
- увеличение количества;
- уменьшение количества;
- удаление товара;
- очистка корзины;
- автоматический расчёт общей стоимости;
- отображение количества товаров;
- ограничение количества товара доступным остатком;
- динамическое обновление содержимого корзины.

### Поиск и работа с состоянием

Для работы с товарами реализованы отдельные функции поиска:

- поиск товара по ID;
- поиск товара в корзине;
- получение текущего количества товара;
- получение общей стоимости корзины;
- получение сводной информации о корзине.

Состояние корзины хранится в JavaScript и обновляется при каждом действии пользователя.

### Динамический интерфейс

После изменения корзины интерфейс автоматически обновляется без перезагрузки страницы.

Используются:

- DOM-манипуляции;
- обработчики событий;
- динамическое создание элементов;
- делегирование событий для динамических кнопок;
- визуальные уведомления пользователя.

## 📐 Responsive Design

Интерфейс адаптирован под различные размеры экрана.

Используются:

- CSS Grid;
- Flexbox;
- Media Queries;
- адаптивное изменение количества колонок;
- перестройка каталога и корзины на небольших экранах.

На мобильных устройствах элементы интерфейса перестраиваются в вертикальную структуру для более удобного использования.
